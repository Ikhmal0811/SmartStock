
# SmartStock
### Inventory & Sales Intelligence System

SmartStock is a full-stack inventory and sales management
system developed as a software engineering portfolio project.

## Technologies

### Backend
- C# / ASP.NET Core Web API
- Entity Framework Core
- PostgreSQL
- JWT Authentication (in progress)
- BCrypt Password Hashing

### Frontend (Planned)
- React.js

### Analytics (Planned)
- Python Sales Forecasting

## Features

### Implemented
- Category Management (CRUD)
- Product Management (CRUD)
- Supplier Management (CRUD)
- Stock In and Stock Out
- Inventory Movement Tracking
- Sales Transaction Processing
- Automatic Inventory Deduction
- Sales Total and Gross Profit Calculations
- PostgreSQL Transactions

### In Progress
- JWT Authentication
- Role-Based Authorization

### Planned
- React Dashboard
- Sales Analytics
- Low Stock Alerts
- Demand Forecasting
- Automated Testing
- Deployment

## Architecture

SmartStock uses a layered architecture:

- SmartStock.API
- SmartStock.Application
- SmartStock.Domain
- SmartStock.Infrastructure
- SmartStock.Tests
